# GhostStory AI 👻

A spooky story generator powered by open-source AI.

## Features
- Generate original ghost stories.
- Choose characters and spooky settings.
- Select scary, mysterious, or emotional moods.
- Runs locally using Ollama.

## Tech Stack
- HTML, CSS, JavaScript
- Ollama
- Qwen 2.5 (1.5B)

## Why Open Innovation?
GhostStory AI uses an open-weight model running locally. This gives users more control over their prompts and stories, reduces dependence on hosted AI services, and makes experimentation accessible.

## Run Locally
1. Install Ollama.
2. Download `qwen2.5:1.5b`.
3. Run `python -m http.server 8003` in the project folder.
4. Open `http://localhost:8003`.
